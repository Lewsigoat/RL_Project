# Niche decision packet

Scored 2026-09-03 from live web SERPs (US-English results). Keyword Difficulty tools were not used as the decision. Domains were checked via Cloudflare DNS NS lookups (Status 3 / NXDOMAIN treated as likely available).

## Chosen niche

**US DIY pressure-washer fitting identification:** which connector is on the pump, hose, gun, wand, and accessory, and which adapter actually seals.

One sentence: people who own a consumer pressure washer and need to replace a hose, gun, foam cannon, or nozzle without guessing M22-14 vs M22-15 vs 1/4" vs 3/8" quick-connect vs a Kärcher clip.

**Working site name:** PW Fit Guide  
**Domain candidate:** `pwfitguide.com` (NXDOMAIN)  
**Backup domains:** `m22guide.com`, `washerfit.com`, `pwconnectors.com` (all NXDOMAIN)

## Runner-up

**Window screen spline sizing** (0.140 vs 0.160, pet screen drop-a-size, groove measurement). Safer and slower-changing, but cheaper products, spring-seasonal, and Phifer already publishes the canonical chart.

## Stage A — 42 seed niches

Each seed is *audience + job-to-be-done + page inventory*.

### Compatibility / fitment

1. DIYers who need pressure-washer hose/gun/wand connectors identified — one page per fitting type plus a brand table.
2. Homeowners matching garden-hose GHT to NPT/BSP pipe — thread charts and adapters.
3. Garage owners mixing industrial vs automotive air-compressor quick-connects — profile ID plus body size.
4. Photographers matching lens filter threads and step-up rings — thread sizes and vignetting notes.

6. Cyclists choosing Presta vs Schrader tubes and valve length — rim hole and depth.

### Pre-build checks on the winner

- Demand is not a one-weekend fad (hose/gun replacements are year-round in the US; spring/summer heavier).
- `pwfitguide.com` has no NS records (likely registrable ~$12/year). Confirm at the registrar before paying.
- First ten pages can be written from manufacturer docs (AR Blue Clean M22 explainer, Shop Joe hose FAQ, Kärcher-adapter product specs) plus public thread conventions (M22 = 22 mm metric thread; GHT = 3/4-11.5 NH), not from scraping ranking blogs.

### Why the runner-up lost

Spline has a cleaner SERP in spots but Phifer already published the chart, AdSense RPM will be weaker (low-ticket vinyl cord), and inventory is thinner. NEMA pays better and is still somewhat beatable, but a wrong page can be dangerous and looks like YMYL to reviewers.
