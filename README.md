# Polymarket Forecast Study

Reproduzierbare Forschungsarbeit zur Frage, ob ein strikt zeitgerechtes Modell
binäre Polymarket-Verträge besser prognostiziert als der damalige Marktpreis
und historische Basisraten.

Der vollständige Schnellstart und die empirischen Resultate werden nach dem
reproduzierbaren Ergebnislauf ergänzt. Das vorab festgelegte Design steht in
[`docs/preregistration.md`](docs/preregistration.md), der Forschungsstand in
[`docs/literature_review.md`](docs/literature_review.md).
